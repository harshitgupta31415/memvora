# Primary technical references

These official or upstream references support the chosen primitives. The complete Memvora workflow, transaction guarantees, authorization rules and deletion fencing are application responsibilities to implement and verify. API and version details should be checked again when an integration is built; the repository lockfile records installed versions.

| Topic                       | Reference                                                                                                                                                                                                             | Implementation use                                                            |
